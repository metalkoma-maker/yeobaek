# 글자 수 기준

집필 화면과 원고 목록의 기본 글자 수는 **본문의 띄어쓰기 포함, 줄바꿈 제외**로 통일한다. 제목은 세지 않는다. 한글, 숫자, 문장부호, 이모지는 Unicode 코드 포인트 단위로 센다. 예를 들어 `가 나\n다😀`는 5자다.

전체 글자 수와 오늘의 증감에 같은 기준을 사용한다. 여러 기준을 기본 화면에 함께 표시하지 않는다. 웹, 서버, 아이폰 앱의 계산을 함께 맞춘다.

기존 서버에는 공백 제외 기준으로 저장된 당일 `daily.delta`가 있을 수 있다. 데이터와 당일 숫자를 보존하기 위해 그날은 기존 기준으로 계속 계산하고 화면에 임시로 표시한다. 다음 한국 날짜부터 새 기준을 적용한다. 전환 날짜는 `schema_migrations`의 `count_spaces_v1`에 한 번 기록되며, 원고 본문과 기존 일별 기록은 다시 쓰지 않는다.
