# 약관·개인정보 처리방침 공개 계획

이 폴더의 문서는 검토용 초안이다. `XX`와 운영 확인 항목이 남은 상태로 가입 동의를 받지 않는다.

## 타이피 문서에서 참고한 점

[타이피 이용약관](https://typie.co/legal/terms)과 [개인정보처리방침](https://typie.co/legal/privacy)의 항목을 대조했다. 가입·계정 관리, 회원 원고의 권리, 서비스 변경·탈퇴·책임, 개인정보 항목·보유 기간·쿠키·위탁·국외 이전·문의처의 구조만 참고했다. 문구는 소설여백의 실제 동작에 맞춰 새로 작성했다. 타이피의 결제·휴대폰 인증·협업·광고·마케팅 동의 조항과 해당 업체 목록은 소설여백에서 운영하지 않으므로 포함하지 않았다. 약관을 읽지 않은 책임을 전부 회원에게 돌리거나, 미응답을 동의로 간주하거나, 일률적으로 환불을 제한하는 문구도 가져오지 않았다.

맞춤법 검사 방식, 비밀번호 찾기 메일, 구독 정책 등 출시 전 기능의 세부 사항은 공개 문안에서 제외했다. 실제 도입 시 처리방침·별도 기능 안내를 갱신한다.

## 공개 전 확인

1. 운영 주체·문의처·백업 스냅샷 보존·업체 위탁 및 국외 처리 여부를 확인해 초안을 확정한다.
2. 만료 세션·시도 제한 기록의 정리 기간을 코드와 문서에서 일치시킨다. 비밀번호 재설정 메일을 활성화할 때는 토큰 기록의 처리도 추가한다. 탈퇴 계정이 백업 복구로 되살아나지 않도록 절차를 정한다.
3. 가입 화면과 로그인 화면에서 약관·처리방침 전문을 볼 수 있게 한다. 가입에는 약관 확인 절차를 두고 적용 버전과 시각을 서버에 기록할지 결정한다. 마케팅 수신과 원고의 외부 맞춤법 검사 동의는 가입 조건과 묶지 않는다.
4. 기존 회원에게 중요한 변경을 알리고, 적용 시점과 필요한 추가 동의 범위를 확정한다.
5. 합성 회원으로 가입·약관 열람·탈퇴·백업 정리 검증을 마친 뒤 별도의 운영 배포를 요청한다. 현재 진행 중인 PR13 배포 요청에는 이 문서와 새 가입 기능을 섞지 않는다.
6. 만 14세 미만 회원가입을 허용할지 정한다. 연령 제한을 둘 경우 가입 흐름에서 실제로 확인해야 한다. 유료 구독이 도입되면 별도 결제·환불 정책과 미성년자 결제 절차를 작성한다.
