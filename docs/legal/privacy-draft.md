## 한눈에 보기

| 목적 | 처리하는 정보 | 보유 기준 |
| --- | --- | --- |
| 회원 가입·로그인·계정 관리 | 이메일, 비밀번호의 단방향 해시, 가입 시각, 세션 토큰의 해시 | 회원 탈퇴까지. 로그인 쿠키는 발급 후 최대 30일, 서버 세션의 만료 값도 30일이나 만료 행 정리 절차는 확인·개선 필요 |
| 원고 작성·복원 | 제목, 본문, 저장·수정 시각, 최근 수정 이력, 복원 지점, 작성 통계, 원고 순서 | 원고 또는 계정 삭제까지. 복원 지점의 개수·기간 정책은 별도 확인 필요 |
| 로그인 및 복구 요청 남용 방지 | 이메일·접속 IP 조합에서 계산한 해시, 시도 횟수·시각 | 현재 DB에서 자동 만료 삭제가 구현되지 않아 보유 기간 확정·정리 기능 필요 |
| 비밀번호 재설정 | 이메일로 보낸 일회용 링크의 토큰 해시 | 30분 후 사용할 수 없으나, 만료 행의 전체 정리는 아직 구현되지 않아 보유 기간 확정·정리 기능 필요 |

비밀번호 원문은 저장하지 않습니다. 원고 본문은 서비스 서버와 백업에 저장되며 종단 간 암호화가 적용된 상태가 아닙니다. 권한 있는 운영자가 기술적으로 접근할 수 있으므로 접근 범위·기록·보호 조치를 운영 절차로 확인해야 합니다.

## 수집·이용과 법적 근거

소설여백은 회원 계약의 체결·이행을 위해 이메일과 인증 정보, 원고와 저장 이력을 처리합니다. 접속 남용 방지와 보안 유지에 필요한 최소한의 정보를 처리합니다. 실제 법적 근거와 필수·선택 항목은 운영 주체의 검토를 거쳐 확정합니다. 광고성 정보 발송이나 원고의 모델 학습은 현재 기능에 포함되지 않습니다.

## 기기와 쿠키

로그인 상태를 유지하기 위해 `novel_session` 쿠키를 사용합니다. 브라우저에는 저장 실패에 대비한 원고 임시본과 본문 글자 크기 설정이 로컬 저장소에 남을 수 있습니다. 브라우저의 임시본은 같은 기기의 다른 사용자도 접근할 수 있으므로 공용 기기에서는 로그아웃과 기기 저장 데이터를 확인해야 합니다. 탈퇴 동작은 해당 계정에 연결된 브라우저 임시본을 지웁니다. 앱 기기의 오프라인 임시본 삭제 동작은 앱 버전별로 검증해야 합니다.

## 백업과 파기

회원 탈퇴 시 운영 DB의 회원, 원고, 수정 이력, 복원 지점, 작성 통계와 세션은 삭제됩니다. 운영 DB 삭제와 백업본 삭제는 같은 시점에 일어나지 않습니다. 현재 코드의 서버 로컬 자동 백업 정리 기준은 파일 생성 후 **7일 경과**, Google Drive 일일 백업 정리 기준은 **30일 경과**입니다. 두 기간은 백업 작업이 실제 실행되고 정상 완료된 경우의 코드상 기준입니다. 배포 전 SQLite 스냅샷의 보존 기간, 백업 작업 실행 상태, 탈퇴 계정의 과거 백업본 처리 절차는 **XX: 운영 확인 필요**입니다. 백업본은 복구 목적으로만 사용하고, 복구 후 이미 탈퇴한 계정이 되살아나지 않도록 재삭제 절차를 마련해야 합니다.

## 외부 업체·국외 이전

운영 서버 제공업체, Google Drive 백업 제공업체, 메일 발송 업체가 실제로 처리하는 정보, 소재 국가, 처리위탁 관계와 국외 이전 여부는 **XX: 계약·설정 확인 필요**입니다. 미리보기용 Cloudflare 임시 터널은 운영 서비스의 상시 처리 수단으로 보지 않습니다. 맞춤법 검사는 현재 연결되어 있지 않습니다. 향후 외부 교정 API를 쓰면 사용자가 검사를 요청한 글의 일부가 해당 업체에 전송되므로, 전송 범위, 보관·학습 여부, 국가, 법적 근거를 확인해 이 방침과 검사 화면에 먼저 반영합니다.

## 이용자의 권리와 안전조치

회원은 서비스에서 본인 원고를 열람·수정·내려받고, 계정 설정에서 비밀번호 변경과 탈퇴를 요청할 수 있습니다. 그 밖의 개인정보 열람·정정·삭제·처리정지 요청 및 문의는 **XX**로 접수하며 관계 법령에 따라 처리합니다. 권리 행사가 제한되는 경우에는 사유를 안내합니다.

서비스는 계정별 원고 접근 제한, 비밀번호·세션 토큰의 해시 저장, 쿠키의 HttpOnly 및 SameSite 설정, 요청 위조 방지 검사를 사용합니다. 운영 HTTPS와 보안 쿠키 설정, 백업 암호화·접근 권한, 로그 보유 기간은 실제 서버 설정 확인 후 기재합니다.

## 변경 안내

처리방침을 변경하면 변경 내용과 시행일을 서비스에 공개합니다. 수집 항목, 외부 제공·국외 이전, 보유 기간 등 이용자 권리에 중요한 변경은 필요한 사전 안내와 법적 절차를 거칩니다.

## 공개 전 확인할 사실

1. 운영 주체의 법적 명칭, 연락처, 개인정보 보호책임자 또는 담당 부서, 시행일.
2. 운영 서버·백업·메일 제공업체와 데이터 처리 국가, 위탁·국외 이전 조건.
3. 자동 백업 작업의 실제 실행 상태, 배포 스냅샷 보존 기간, 탈퇴 후 백업본 처리 절차.
4. 만료 세션·시도 제한 해시·재설정 토큰의 DB 정리 기능과 확정 보유 기간.
5. 운영 HTTPS 및 백업 암호화·접근 통제 확인. 모바일 앱 로컬 임시본 삭제 동작.
6. 맞춤법 검사 방식 결정 후 외부 전송 범위·제공업체 보관 정책과 동의 방식.
