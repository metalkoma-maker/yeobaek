# 맞춤법 검사 결정안

상태: 설계·공급자 확인 단계. 운영 원고를 외부 검사기에 전송하는 기능은 아직 구현하지 않는다.

## 서비스에 맞는 사용 흐름

1. 원고 화면에서 사용자가 `맞춤법 검사`를 누른다. 자동 저장이나 타이핑은 검사를 호출하지 않는다.
2. 외부 서비스를 쓰는 경우, 검사 대상(선택한 문장 또는 현재 글)과 제공업체를 보내기 전에 명확히 보여준다. 확인하지 않으면 전송하지 않는다.
3. 결과는 원문과 제안을 비교하고 **한 항목씩 적용·건너뛰기**를 선택한다. 전체 자동 교체는 기본 동작으로 두지 않는다.
4. 검사 중 원고가 바뀌면 오래된 결과의 적용을 거절한다. 결과 적용은 기존 자동 저장·수정 이력·충돌 복구 흐름을 따라야 한다. 검사 요청과 응답을 별도 DB에 저장하거나 서버 로그에 남기지 않는다.
5. 검사기가 실패하면 원고를 바꾸지 않는다. 제공업체의 교정은 문학적 표현·인물 이름을 잘못 고칠 수 있음을 짧게 알린다.

## 방식 비교

| | 외부 한국어 교정 API | 자체 서버 처리 |
| --- | --- | --- |
| 품질·개발 | 한국어 교정·띄어쓰기 결과와 수정 위치를 제공하는 상용 API가 있음 | 적합한 엔진의 설치·품질 검증이 선행되어야 함 |
| 원고 전송 | 사용자가 요청한 글이 업체로 전송됨 | 자체 서버 밖으로 보내지 않을 수 있음 |
| 비용·운영 | 사용량 한도 또는 과금, API 키·장애 관리 | 라이선스, 서버 자원·업데이트·장애 관리 |
| 현 배포 환경 | 서버 프록시·비밀키·요청 제한·개인정보 안내 추가 필요 | 새 서비스·의존성·배포 절차가 필요하여 현재 제한된 7파일 배포 범위를 벗어남 |

예시로 `바른`의 공식 REST API는 `CorrectError`와 수정 블록을 제공한다. 2026-10-21 공개 가격표는 Free 월 5만 어절, Standard 월 9,900원/50만 어절, Business 월 49,000원/300만 어절, 설치형은 Enterprise 별도 문의로 표시한다. 이 금액·한도를 다수 회원에게 제공하는 서비스에 그대로 적용할 수 있는지는 약관·계약 확인이 필요하다. 공식 설치 안내는 맞춤법 검사기를 클라우드 전용이라고 설명하지만 가격표는 Enterprise 설치형을 별도로 표기하므로, 자체 설치를 가정하고 개발하기 전에 업체 확인이 필요하다. 공개 개인정보 처리방침에서 **API에 보낸 원고의 보관·학습·국외 처리 조건을 특정하지 못했다**. 이 조건이 계약으로 확인되기 전에는 실제 회원 원고로 시험하지 않는다.

## 다음 결정

- 외부 전송을 허용할지, 자체 처리만 허용할지 정한다.
- 외부 전송을 허용하면 제공업체에 **원고 보관 여부·기간, 학습 사용 여부, 처리 국가, 서비스 재판매/다수 회원 제공 조건**을 서면으로 확인한다. API 키는 서버 비밀 저장소에 둔다.
- 자체 처리만 허용하면 상용 설치형 계약 또는 품질이 검증된 다른 엔진과 운영 서버 용량을 먼저 확인한다.
- 어느 방식이든 가짜 문장으로 품질·실패·동시 수정 테스트를 하고 사용자 화면에서 확인받은 뒤에만 운영 배포를 검토한다.
