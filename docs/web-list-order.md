# 웹 원고 목록과 TXT 내려받기

## 목록 기준

- 고정한 원고를 맨 위에 놓습니다. 여러 개를 고정하면 **고정한 순서**를 유지합니다. 고정한 원고를 수정해도 고정 원고끼리의 순서는 바뀌지 않습니다.
- 고정하지 않은 원고는 최근 수정한 순서로 표시합니다. 성공적으로 저장된 원고가 맨 위로 이동합니다. 수정 시각이 같은 경우에도 빠른 연속 저장을 구분하도록 새 수정 시각을 초 단위 이하로 기록합니다.
- 각 원고 행의 핀 아이콘을 눌러 고정하거나 해제합니다. 고정 상태는 계정에 저장돼 다른 기기에서도 같습니다. 드래그와 Alt+↑/↓ 순서 변경은 더 이상 제공하지 않습니다.
- 이전에 저장한 수동 순서 데이터는 삭제하지 않지만 목록 정렬에 적용하지 않습니다. 이미 열린 예전 화면의 수동 정렬 요청은 409로 거절해 사용자의 원고나 기존 기록을 바꾸지 않습니다.

## 서버와 데이터

`GET /api/manuscripts`는 본인 원고를 위 기준으로 반환하고 각 원고에 `pinned`를 포함합니다. `PUT /api/manuscripts/<id>/pin`은 `{ "pinned": true|false }`를 받아 해당 원고의 고정 상태만 변경합니다. 로그인, 같은 Origin, CSRF, 원고 소유권 검사를 유지합니다. 여러 번 고정해도 기존 고정 순서는 바뀌지 않습니다.

새 `manuscript_pins` 표는 기존 DB에 추가됩니다. 기존 `manuscript_order` 표와 행은 유지합니다. 고정·해제는 원고 본문, 버전, 최근 수정 이력, 일별 글자 수를 변경하지 않습니다. 계정과 원고 삭제 시 핀 행도 함께 삭제됩니다.

웹은 약 10초 간격으로 다른 기기의 수정·고정 상태를 확인합니다. 작성이나 저장 중에는 목록 갱신을 미루고, 오래 걸린 조회가 방금 저장하거나 고정한 결과를 되돌리지 않도록 합니다.

## TXT 내려받기

TXT 첫 줄에는 내려받는 순간의 한국시간을 초 단위까지 표시합니다. 현재 화면의 제목과 본문을 그대로 내려받으므로 저장 대기 중인 입력도 포함합니다.

## 검증 및 운영

임시 DB 단위 검사는 최근 수정순, 오래된 수동 순서 무시, 고정 순서, 다른 계정 접근 거절, 삭제 시 정리를 확인합니다. Chromium 합성 원고 검사는 저장 뒤 정렬, 핀·해제, 다른 브라우저 동기화, 실패 및 지연된 조회, TXT와 사본 만들기를 확인합니다. 운영 배포에는 기존 백업·건강 검사·롤백 절차를 적용합니다. 이 문서와 PR은 운영 배포를 실행하지 않습니다.
