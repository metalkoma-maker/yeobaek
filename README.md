# 소설여백 — 소설 집필 앱 첫 버전

여러 작가가 이메일과 비밀번호로 가입하는 가벼운 집필 앱입니다. PC와 휴대폰이 **같은 서버 주소**에 접속하면 같은 원고를 이어 씁니다. 타 서비스의 코드·디자인·브랜드는 사용하지 않았습니다.

## 구현한 기능
- 회원가입·로그인·로그아웃, 회원별 원고 접근 제한
- 원고 목록·생성·제목 및 본문 편집
- 마지막 입력 후 0.7초 자동 저장, 저장 상태 표시
- 전체 글자 수와 오늘 순증감 표시 (공백·줄바꿈 제외, 한국시간 자정 기준)
- 10초 간격으로 수정 여부 확인, 동시 수정 충돌 시 입력 보존 및 서버 원고 비교 안내
- TXT 내려받기, PC·휴대폰 반응형 화면, 설치형 웹앱 기본 설정

예: 오늘 500자를 추가하고 100자를 지우면 +400자. 새 원고에 붙여넣은 글도 오늘 증가량으로 계산합니다. 오늘의 통계는 성공적으로 저장된 편집의 합계입니다. 화면의 수치는 저장 대기 중인 입력도 반영합니다. 결합 이모지는 유니코드 코드 포인트 기준으로 여러 글자로 셀 수 있습니다.

## PC에서 실행
Python 3.11 이상을 설치한 후 이 폴더에서 실행합니다.

```sh
python -m venv .venv
```

Windows:
```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

macOS / Linux:
```sh
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

브라우저에서 http://localhost:8000 을 엽니다. 첫 계정은 직접 가입합니다. 같은 Wi-Fi에서는 PC의 내부 IP:8000으로 휴대폰에서 접속할 수 있습니다(방화벽 허용 필요). 이 경우 PC가 켜져 있어야 합니다. PC를 끈 상태에서도 쓰려면 클라우드 서버에 배포해야 합니다.

## 클라우드 배포
Dockerfile이 포함되어 있습니다. 지속 디스크를 지원하는 Docker 서버에 올리고 `/data`에 영구 볼륨을 연결합니다. 데이터베이스가 임시 디스크에 있으면 재배포 시 원고가 사라질 수 있으므로 영구 볼륨은 필수입니다.

```sh
docker build -t yeobaek .
docker run --rm -p 8000:8000 -v yeobaek-data:/data yeobaek
```

이 명령은 HTTPS 역방향 프록시 뒤의 운영 설정입니다. 로컬 HTTP Docker 테스트는 `-e COOKIE_SECURE=0`을 추가합니다. 운영에서는 HTTPS와 `COOKIE_SECURE=1`을 사용합니다. 프록시는 원래 Host를 전달해야 합니다. 일반 배포는 Gunicorn을 사용하며 Flask 개발 서버는 운영용으로 사용하지 않습니다.

현재 운영 웹은 https://yeobaek-write.duckdns.org 입니다. 운영 DB·관리자 설정·인증키는 저장소에 포함하지 않습니다. 내부 백업과 암호화된 Google Drive 백업은 서버에서 별도로 설정되어 있습니다. 데이터베이스는 백업해야 하며, 많은 사용자를 대상으로 운영할 때는 관리형 DB·공유 속도 제한·운영 모니터링을 보완합니다.

## 이번 버전의 범위
- 이메일 형식을 확인하며 비밀번호는 scrypt로 해시합니다. 이메일 소유권 확인·비밀번호 재설정·회원 탈퇴는 아직 미구현입니다. 일반 공개 출시 전에 추가해야 합니다.
- 온라인 사용을 전제로 합니다. 기기 임시 보관본 B와 서버 저장본 A를 비교할 수 있습니다. B를 불러온 뒤에는 명시적으로 저장해야 서버에 반영됩니다. 최근 변경 전 원고 50개를 수정 이력으로 보관합니다. 완전한 오프라인 앱은 아직 아닙니다.
- PWA 설치에 필요한 HTTPS와 기본 manifest를 준비했습니다. 앱스토어용 iOS 빌드·서명·심사 제출은 아직 진행하지 않았습니다. 앱 아이콘 PNG와 iOS 설치 최적화도 출시 단계에 보완합니다.
- 원고 삭제는 넣지 않았습니다. TXT 파일로 원고를 보관할 수 있습니다.

## 검증
```sh
python -m unittest discover -s tests -v
```
회원 간 원고 격리, CSRF 검사, 동일 계정의 두 세션 간 조회, 글자 수 집계, 날짜 변경·삭제량, 수정 충돌, 로그아웃을 확인합니다.

## 코드 관리
- `.gitignore`는 DB·백업·관리자 설정·비밀키를 제외합니다. 이미 추적된 파일은 자동 제거되지 않습니다.
- 백업 스크립트는 운영 서버용입니다. 개발 환경에서 실행하지 마세요.
- 서버 운영자는 현재 평문 원고에 기술적으로 접근할 수 있습니다. 종단간 암호화는 보류했습니다.
- 모바일 목록 우선 화면, 최근 수정일, 글자 크기 5단계, 관리자 통계가 구현되어 있습니다.
